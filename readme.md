# PL-300: Microsoft Power BI Data Analyst

Este repositorio contiene los ejercicios prácticos para el curso de Microsoft [PL-300: Analista de Datos de Microsoft Power BI](https://docs.microsoft.com/en-us/learn/certifications/courses/PL-300T00). Los laboratorios están diseñados para acompañar los materiales de aprendizaje y permitir a los estudiantes practicar utilizando las tecnologías que describen.


¿Qué estamos haciendo?

- Para apoyar este curso, necesitaremos realizar actualizaciones frecuentes en el contenido del curso para mantenerlo al día con los servicios de Power BI utilizados en el curso. Estamos publicando las instrucciones de laboratorio y los archivos de laboratorio en GitHub para permitir contribuciones abiertas entre los autores del curso y los MCTs para mantener el contenido actualizado con los cambios en la plataforma de Power BI.


## ¿Qué pasa con los cambios en el manual del estudiante?
- Revisaremos el manual del estudiante trimestralmente y actualizaremos a través de los canales normales de publicación según sea necesario.
